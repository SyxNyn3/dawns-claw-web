# Dawns Claw — Aerospace Command

Premium aviation concierge management, autonomous systems, and aerospace consultancy — Charleston, South Carolina (KCHS corridor, adjacent to Boeing South Carolina).

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Elite landing page — white-glove aviation management vision |
| `join.html` | Multi-role intake portal (A&P/IA, Part 107, apprentice, infrastructure partner) |
| `academy.html` | License direction engine — Part 107, A&P, IA, avionics, management tracks |
| `donate.html` | Hardware requisition manifest + 501(c)(3) proxy write-off protocol |
| `network.html` | B2B affiliate classes and joint cross-marketing venture formats |

## Stack

- Static HTML5 — no build step required
- Tailwind CSS via CDN (custom palette: cream `#FDFBF7`, gold `#D4AF37`, forest `#1B4D3E`, rose accents)
- Google Fonts: Cormorant Garamond / Inter / JetBrains Mono
- Shared design system: `assets/css/dc.css`
- Interactions: `assets/js/main.js`, `join.js`, `academy.js`

## Run locally

Open `index.html` directly, or serve the folder:

```powershell
python -m http.server 8000
```

→ http://localhost:8000
